# Deploying CrowdChain

**Frontend → Vercel** (static SPA) · **API → Render** (always-on Node service) · **DB → MongoDB Atlas** (free M0) · **Chain → Sepolia testnet** (free test ETH).

> The frontend needs **zero config to work** — if the API is unreachable it falls back to demo data. Deploy it first if you want to see the site live immediately; add the backend when ready.

---

## 1. Frontend on Vercel

1. Push this repo to GitHub.
2. Vercel → **Add New → Project** → import the repo.
3. Settings:
   - **Root Directory**: `frontend`
   - Framework preset: Vite (auto-detected)
4. Environment Variables:
   | Key | Value |
   |---|---|
   | `VITE_API_BASE_URL` | `https://<your-render-service>.onrender.com/api` (add after step 2; leave unset initially — demo data mode) |
5. Deploy. `frontend/vercel.json` already rewrites all routes to `index.html`, so deep links like `/explore` work.

After the Render URL exists, add `VITE_API_BASE_URL` and **redeploy** (env vars are baked at build time).

---

## 2. Database on MongoDB Atlas (free)

1. mongodb.com/cloud/atlas → create a free **M0** cluster.
2. **Database Access** → add a user (username + password).
3. **Network Access** → allow `0.0.0.0/0` (Render's free tier has no static IPs).
4. Copy the SRV connection string:
   `mongodb+srv://<user>:<pass>@<cluster>.mongodb.net/crowdfunding`

---

## 3. Contract on Sepolia

1. Get a free RPC URL from Alchemy or Infura (Sepolia, no key billing on free tier).
2. Create a **burner** wallet for deployment (never your main wallet). Fund it with test ETH from the Google Cloud Web3 faucet or Alchemy faucet.
3. Fill in `backend/.env`:
   ```
   SEPOLIA_RPC_URL=https://eth-sepolia.g.alchemy.com/v2/<key>
   DEPLOYER_PRIVATE_KEY=<burner key>
   ```
4. Deploy:
   ```bash
   cd backend
   npm run hardhat:compile
   npx hardhat run scripts/deploy.js --network sepolia
   ```
   This writes `src/blockchain/contracts/Crowdfunding.sepolia.json` **and** `Crowdfunding.latest.json`. **Commit the latest file** — the Render service reads the contract address + ABI from it.

---

## 4. API on Render

1. Render → **New → Blueprint** → select this repo. The `render.yaml` at the root provisions `crowdchain-api` (Node, root dir `backend`, health check `/health`).
2. Fill the `sync: false` env vars when prompted:
   | Key | Value |
   |---|---|
   | `MONGODB_URI` | Atlas SRV string from step 2 |
   | `RPC_URL` | Your Sepolia Alchemy/Infura URL |
   | `CORS_ORIGIN` | `https://<your-vercel-app>.vercel.app` |
   | `CONTRACT_ADDRESS` | Optional — only if you skipped committing `Crowdfunding.latest.json` |
3. Deploy. First request after idle may take ~50s (free tier spins down).

---

## 5. Frontend users: wallet setup

Users interact with **Sepolia** (chain ID 11155111), not your deployer wallet:

1. Install MetaMask → add the **Sepolia network** (built into MetaMask under test networks).
2. Get free test ETH from a faucet for their wallet.
3. Connect on the Vercel site → sign-in message → contribute/vote flows.

> Money never touches mainnet: Sepolia ETH is valueless and faucets are free.

---

## Notes

- **MongoDB is a mirror; the chain is the truth.** Every write (contribute, vote, release) is a real Sepolia tx whose hash the API verifies against the contract before recording.
- **The polling indexer is off on Render.** The primary write path — API-verified tx hashes — works fully serverless-hosted. The indexer (`eventListener.js`) only auto-starts in local dev and exists as an audit-trail supplement; a Vercel Cron can enable it later if needed.
- **JWT_SECRET** is auto-generated by the blueprint. Rotating it logs users out (wallet re-sign).
- **Render free tier idle**: after 15 min of inactivity the API sleeps; the frontend silently falls back to demo reads until it wakes.
